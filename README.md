A one-page atlas summing up Monday 23 November 2026 in one image: 36 stories across seven regions, drawn entirely in code (Node 22, standard library only — bitmap font, polygons, pictograms, no assets).

Treatment (distinct from R2): teal / cream / black palette — black masthead, one night-rescue hero panel, a teal numbers strip, a pale-teal world map with numbered pins and a region legend, and a clean 36-story index. Every story is dated Monday 23 November 2026, with a DATE CHECK strip calling out the near-miss dates.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `entry.png` (1024×1024) to the output directory. Deterministic: two runs write byte-identical output.
