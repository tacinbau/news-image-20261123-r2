# The World in One Day — Monday 23 November 2026

A one-page newspaper image summing up 23 November 2026's world news: 36 stories across 7 regions, drawn in code (Node 22, standard library only). The program renders `entry.png` deterministically — run it twice, get the same bytes.

Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
